# Setting up new personal Mac

Make the caps lock -> ctrl
System Settings -> Keyboard -> Keyboard Shortcuts -> Modifier Keys -> Swap caps lock and ctrl
-> Desktop and Dock
-> Turn on automatically hide and show the Dock
-> Turn on group windows by application

1. Install Homebrew

Using `brew`, install the following:
- `git`
- `neovim`

2. Install Helium browser

Settings - Appearance -> Browser Layout -> Vertical

3. Install aerospace
